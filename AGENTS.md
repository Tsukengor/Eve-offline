# Игровые спрайты

Создавай растровые спрайты для всех добавляемых игровых объектов и типов окружения. Храни изображения в `assets/` и подключай их к игровым сценам в рамках той же задачи. Если состояние объекта влияет на решения игрока, покажи его отдельным спрайтом, кадром или визуальным изменением спрайта. Проверяй читаемость изображений в сцене в игровом масштабе.

Для арта используй единый стиль проекта: пиксельная графика, вид сверху, индустриальные космические интерьеры, тёмно-синие поверхности и цветовые акценты. У объектов и персонажей сохраняй прозрачный фон.

# Синхронизация с GitHub

После завершения каждой задачи по разработке запусти регрессии Godot, проверь diff и включи в коммит только относящиеся к задаче изменения. В этом проекте пользователь разрешил отправлять проверенные обновления в `main` публичного репозитория `Tsukengor/Eve-offline` через настроенный `origin`. Сверяй ветку с удалённой перед отправкой и проверяй, что GitHub получил коммит. Рабочие настройки, секреты и локальные сборки остаются вне Git.

Публикуй готовые версии на GitHub Releases через версионные теги `v*`. Workflow запускает регрессии и прикладывает архивы Windows и Linux с контрольными суммами.
